# KGR-PINN

This repository contains the code associated with the manuscript:

**“Kernel Guided Refinement PINN to Solve PDE and Dynamical System”**

The manuscript is currently **under review**.

Currently, the repository provides the **Allen–Cahn equation** implementation. And implementations for the **KdV equation, Lorenz system, and Zakharov equation** will be made available upon publication of the manuscript.
